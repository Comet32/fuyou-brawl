# 福佑大乱斗 · 图鉴与攻略 — 设计共识

> 来源：2026-09-29 grilling 会话。后续改动请直接修改本文件并注明日期。

## 定位

Dota2 游廊自定义游戏《福佑大乱斗》（创意工坊 ID `2841152696`）的非官方图鉴与攻略站。
先给自己和开黑朋友用，后续可能公开推广。

## 功能范围

| 模块 | 说明 |
|---|---|
| 福佑图鉴（首页核心） | 中文 / 全拼 / 首字母 / 效果关键词搜索；分类筛选；本地搜索，页面加载后断网可用 |
| 三选一对比 | 三个输入框各搜一个福佑，并排比较；状态写进 URL（`?ids=a,b,c`）可分享 |
| 英雄搭配 | **所有英雄**都有页面；有资料的写推荐福佑 + 出装 + 思路，没有的显示「待补充」；福佑详情页反查推荐英雄 |
| 版本变动 | 版本列表 + 每个福佑自己的改动历史 |
| 攻略文章 | 新手入门、机制讲解、进阶技巧 |
| **不做** | 评论、投票、投稿后台（贡献走 GitHub PR） |

## 数据

- **来源**（2026-09-29 修订，见下方「变更记录」）：
  - **客观数据**（福佑名称、效果、数值）：从创意工坊 VPK 中的本地化文件 `addon_schinese.txt` 自动提取。用户从 Windows 电脑打包 `steamapps\workshop\content\570\2841152696\` 提供。
  - **攻略观点**（英雄搭配、福佑选择思路）：1～3 个文字社区来源（贴吧 / B 站专栏 / NGA），用自己的话重写并附参考链接，不整篇转载。
  - **版本变动**：对比前后两次 VPK 提取的结果自动得出（创意工坊更新日志基本不写福佑改动）。
- **已接受的风险**：社区攻略覆盖面有限；游戏更新后需要重新提供 VPK 包才能刷新数据。
- **存储**：全部在 Git 仓库里（YAML + Markdown），改文件 → `git push` → 自动构建。

## 图片

- 英雄 / 装备图标：从 Dota2 官方 CDN 下载，转 WebP，仓库内自托管。
- 福佑图标：
  1. 用户从 Windows 电脑打包创意工坊目录 `steamapps\workshop\content\570\2841152696\`，本机用 ValveResourceFormat 解包导出图标；
  2. 缺失的从 B 站视频截取（每次下载视频前征得同意）；
  3. 仍缺的用分类色块占位。

## 更新流程

GitHub Actions 每天 09:00（北京时间）查询创意工坊 `time_updated`，有新版本则自动开 Issue（附更新日志原文 + 处理清单），人工整理后 push。

## 技术与部署

- Astro 纯静态站；Fuse.js 模糊搜索；pinyin-pro 在**构建时**生成拼音索引（不打包进前端）。
- 手机竖屏优先；跟随系统深浅色，默认深色，可手动切换；首页搜索框自动聚焦。
- 主站：GitHub Pages `https://comet32.github.io/fuyou-brawl/`（公开仓库 `Comet32/fuyou-brawl`）。
- 备用：Cloudflare Pages `https://fuyou-brawl.pages.dev`。
- 零成本：不买域名、不备案。以后需要时可加域名 + EdgeOne Pages。
- 本地目录：`~/Documents/GitHub/fuyou-brawl`。

## 已知问题

- 本机代理 `127.0.0.1:7897` 访问 Steam / B 站时 TLS 握手失败；需要外网的步骤要么先修代理，要么放到 GitHub Actions 里跑。
- GitHub 会在公开仓库 60 天无活动后自动停用定时 workflow，需要偶尔 push 或手动重新启用。
