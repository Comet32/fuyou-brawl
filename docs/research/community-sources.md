# 福佑大乱斗社区资料调研

调研日期：2026-09-29（当前游戏版本 2026-09-21）。对应数据文件：

- `tmp/research/blessing-notes.json`：按福佑 id 整理的数值、心得、英雄搭配、品质（593 条）
- `tmp/research/general-tips.json`：通用机制和选福佑思路（40 条），可用来写攻略文章
- `tmp/research/raw/`：原始抓取数据（社区图鉴 API 的 JSON、Steam 改动说明全文、评论）和生成脚本，方便复核

所有心得都是我自己转述的，没有照抄原文。数值照原样记录并附来源。日期早于 2026-03-29 的条目标了 `possibly_outdated`。

## 结论

1. **最有用的是一个社区图鉴站 `http://122.51.0.76:8081`**（标题“福佑大乱斗 — 技能图鉴 Wiki”）。它的公开只读 API 给出了 228 个通用福佑和 345 个英雄专属福佑的颜色（橙/紫/蓝）、数值区间和分类标签，另外还有 22 张英雄“一图流”攻略图。这个站点就是 B 站视频 BV1feAHzJEGH 所附腾讯文档的网页版。本次得到的数值和品质几乎都来自这里。
2. **第二有用的是 Steam 创意工坊的改动说明**（235 条，2026-02-07 以后才属于现在这张图）。里面有 10 多次福佑平衡调整的名单、品质升降、机制改动，还有新增福佑的日期。
3. **B 站的攻略内容基本都在视频里**。UP 主“雨落流殇丶”有 137 个福佑相关视频，其中有一套“从夯到拉”福佑评级。但简介都是空的，所以只能用上标题（能看出英雄和福佑怎么搭）和热评里 UP 主的回复。
4. 贴吧、抖音、NGA、知乎、小黑盒、Reddit 上几乎没有内容：没有“福佑大乱斗吧”，dota2 吧只找到 1 个相关帖子，NGA、知乎、小黑盒、Reddit 都没搜到相关讨论。

## 策略概况（转述）

**福佑怎么抽**
- 每 5 级从 3 个里选 1 个。同一局所有人抽到的品质相同，刷新只换福佑、不换品质（[工坊说明](https://steamcommunity.com/sharedfiles/filedetails/?id=2841152696&l=schinese)）。
- 每局至少有蓝、紫、橙各 1 个，最多 3 蓝、4 紫、5 橙（[改动说明 2026-03-13](https://steamcommunity.com/sharedfiles/filedetails/changelog/2841152696?l=schinese)）。
- 每个英雄有自己的专属福佑池。系统会降低抽到不适配福佑的概率。第一回合不会出电锤思维这类“即战力”福佑。

**大家怎么选**
- **先找专属强化**：多数一图流把英雄专属强化当作核心。例如兽王的 AP斧王、莱恩的死亡一指强化、军团的决斗强化、猛犸的震荡波强化、巫医的巫蛊咒术强化、女王的痛苦尖叫强化（[图鉴站一图流](http://122.51.0.76:8081)）。
- **几乎每篇都推荐的通用福佑**：蓝色的抽血麻将、我要验牌、升舱的钱我来出（22 篇里有 21~22 篇），紫色的越抓越肥（19 篇）和放手一搏（13 篇）。橙色里出现最多的是断头台（16 篇）、铁头娃（13 篇）、电锤思维和会心伤害（各 11 篇）。
- **经济福佑**：评论普遍认为经济福佑都不弱，但一局最好只拿一个（[BV1rNomBCEhA 评论](https://www.bilibili.com/video/BV1rNomBCEhA/)）。
- **随机类福佑**：组合已经成型时尽量别拿九莲宝灯这类随机福佑，完全没抽到好福佑时再拿来赌（[BV1WXGZ6KE8r 评论](https://www.bilibili.com/video/BV1WXGZ6KE8r/)）。
- **法系会心**：法系英雄拿会心伤害时要配法术会心（森海飞霞、血魔、猛犸的一图流都这么写）。
- **魔抗**：本模式物理输出偏少，魔抗堆多了会质变（[BV11ZVs62EK4 评论](https://www.bilibili.com/video/BV11ZVs62EK4/)）。

**常被提到的组合**
- 一拳超人 + 斗气 / 僵王：撼地者、玛尔斯、巨牙海民（UP 主在评论中确认斗气吃一拳超人加成）。
- 超超负荷：力丸（会触发背刺）、灰烬之灵一刀流、狙击手、混沌骑士、风暴之灵。
- 钢琴手：PA（配大招强化和会心伤害）、莉娜（配龙破斩强化）、伐木机、昆卡。
- 放手一搏：宙斯、矮人直升机、工程师、莉娜，实战能叠到 40 层以上。
- 其他：瑶瑶公主 + 蓝胖（给队友护盾和 BKB），苦命鸳鸯 + 司夜刺客（“移动地堡”），奔袭冲撞 + 修补匠。

**梯度**
- 目前没有文字版的福佑梯度表。雨落流殇丶的“从夯到拉”系列（金色、紫色通用两期、技能福佑、三国系列）是最接近梯度表的内容，但评级只在视频画面里。
- 英雄梯度来自一图流：兽王、撼地者评 T0（蓝胖拿到专属、莱恩拿到紫色强化时也算 T0）；女王、火猫、海民 T1；巫医、森海飞霞 T1.5；PA、力丸、军团、熊战士、工程师、昆卡、血魔 T2。
- 图鉴站的“累计增强削弱榜”（2026-08-07）列出了各英雄独立乘区的累计增减幅度。

**外服反馈**：Steam 留言多数是服务器问题，平衡方面常抱怨巨人之戒、坦克和力量英雄太强，也多次要求加禁用英雄。

## 数据说明与冲突

- **数值区间**：图鉴站用 `[a~b]` 表示区间，有时前面带一个样例值，例如 `8940.47[5000-10000]`。JSON 里记为 `range` 和 `sample`。区间具体随什么变化（等级、时间还是随机），来源里没有说明，所以只照原样记录。
- **怎么对应到模板**：我用模板里每个 `{占位符}` 前面的文字，去图鉴描述里找对应的数字。有 10 个值两边单位对不上，比如模板写 `-{v2}%`，图鉴写 `-3秒`，这些标了 `unit_mismatch`，需要人工核对。
- **图鉴原文**：`wiki_text` 字段保存了图鉴站的效果描述原文，只用来核对数值，不要直接发布。
- **品质冲突**：
  - 生命之泉的祝福：图鉴站标蓝色；蓝胖一图流（2026-04-11）放在紫色分区；官方 2026-04-03 写的是“品质上调一档”。
  - 攻击增幅：图鉴标紫色，PA 一图流放在蓝色分区。
  - 技能增强、会心攻击、手快选两个、双层脱敏、技能范围：这些名字对应多个 id，或同名条目在不同颜色分区都出现过，无法确定哪个 id 是哪个颜色，所以没写品质，只写了 `quality_note`。
- **狼王内丹**：工坊说明写“福佑持有者冷却 -3%”，图鉴写 `+1.78[1.5-3]%`。和 overrides 里的 `self_pct: 3` 不矛盾（3 在区间内）。
- **“？”福佑**：英文工坊旧描述是 30% 生命、+20%、15 秒、需要手动发送；图鉴现在是 6% 生命、`[8~24]%`、20 秒、自动发送。以图鉴为准，旧值作为过时信息保留。
- **流离**：图鉴描述还写着“优先转向敌方英雄”，但官方 2026-08-08 已改为不能转向敌方英雄。图鉴有部分条目没跟上更新。
- **对不上的名字**：图鉴里有 8 个专属福佑名字识别错误，对不上 id，例如“变形冷却”“猎手旋镖强化”。一图流里有几个简称也没有可靠对应，例如“先哲之石”“护目镜”“五秒真男人”“生命魔抗”。这些都没有写进数据，名单在 `tmp/research/raw/`，生成日志里也有。
